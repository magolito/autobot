Adding a New Client
Clients are managed directly in Clerk. To add a new one:
Step 1
Create in Clerk
Go to Clerk Dashboard → Users → Create user. Set their name, email, and password.
Step 2
Set publicMetadata
Click the user → Edit public metadata. Add hl_address, initial_capital, and risk_level.
Step 3
Refresh here
Click "Refresh All" above and they'll appear automatically with their live Hyperliquid data.
Open Clerk Dashboard ↗ Clients with hl_address set will auto-appear below.
